# Dental Clinic Website

A modern, elegant, and fully responsive Arabic website designed and developed for a female dentist's clinic. The website provides visitors with a smooth browsing experience, introduces the clinic and its dental services, and makes it easy to explore available appointments and contact the clinic directly.

## Project Overview

The project focuses on creating a professional online presence for a dental clinic through a clean UI, user-friendly navigation, and a consistent visual identity inspired by the clinic's logo.

The website is entirely in Arabic and supports Right-to-Left (RTL) layouts across all pages.

## Features

- **Modern Homepage:** Introduces the dentist and clinic with an attractive and professional layout.
- **Dental Services:** Displays the available dental services in organized and visually appealing sections.
- **Appointments Page:** Shows clinic working days, opening hours, and available appointment slots.
- **WhatsApp Integration:** Provides direct communication through a WhatsApp contact button.
- **Arabic RTL Support:** Fully optimized for Arabic content and right-to-left navigation.
- **Responsive Design:** Adapts smoothly to desktop, tablet, and mobile screens.
- **Reusable Components:** Organized React components for easier maintenance and scalability.
- **Easy Content Management:** Centralized configuration for updating clinic details, contact information, and appointment schedules.
- **Smooth Interactions:** Subtle animations and hover effects for an improved user experience.

## Installation & Setup

1. Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

2. Navigate to the project directory:

```bash
cd dental-clinic-website
```

3. Install dependencies:

```bash
npm install
```

4. Start the development server:

```bash
npm run dev
```

5. Open the local URL provided by Vite in your browser.

## Customization

Clinic information is managed through a centralized configuration file, making it easy to update:

- Dentist and clinic names.
- Clinic introduction.
- Dental services.
- Contact and WhatsApp numbers.
- Clinic address.
- Working days and opening hours.
- Available appointment slots.

This approach allows the clinic owner to update essential information without modifying the main website components.

## Responsive Compatibility

The website is designed to provide a consistent experience across:

- Desktop computers.
- Tablets.
- Smartphones.

## Project Goals

The main goal is to deliver a professional, easy-to-use, and maintainable website that strengthens the clinic's online presence, helps visitors discover its services, and simplifies appointment inquiries.
